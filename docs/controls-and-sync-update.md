# 音量、悬浮窗口与歌词更新

本轮按用户要求只进行代码修改、编译和打包，未运行测试、实际交互验证或独立审查。

- 音量弹层缩小为 56×174 逻辑像素，仅保留百分比和竖向滑条。
- Android 本地会话从 AudioManager 读取实际媒体音量；通过设置变化观察、兼容广播和媒体会话回调发送音量事件。音量指令附带实际值回读，并进行有限的延后确认，不依赖播放/暂停事件。
- 音量事件经过 capabilities 协商；旧 PC 接收带最新进度锚点的完整快照。
- 悬浮播放器使用透明无边框窗口，保留拖动、边缘调整大小和关闭操作。
- 桌面歌词独立默认置顶，工具条新增直达桌面歌词设置的按钮。自动模式根据视口显示可见行，当前原文锚定窗口中心；旧“两行”配置退回自动模式。单行模式保留。
- 原文和辅助文本按同一个文字起点对齐；放大过渡只调整辅助文本位置，不逐帧改变其字体或段落宽度。
- 新增“默认”匹配策略：名称及艺术家必须合理对应；仅尾部括号内容不同允许降级评分。已知时长允许约 4% 的差异，范围约束在 4.5–12 秒；明显不同的标题、时长，以及缺失/未知艺术家不自动匹配。严格、均衡模式仍保留。
- 封面读取支持媒体元数据 Bitmap、内容 URI 和 HTTPS URI；有大小、超时和重试上限，切歌取消旧任务。PC 在能力协商成功后可请求有限次数的快照刷新，界面图片加载失败也有有限重试。

音量同步和手机封面获取机制的修改需要同时更新 Android APK；仅更新 Windows 无法使旧手机端产生新的音量事件。
