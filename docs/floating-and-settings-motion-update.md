# 悬浮播放器与设置交互更新

- 悬浮窗原实现将 x/y 绑定到读取全局设置版本的表达式，同时每次坐标改变都会写设置并广播 settingsChanged。移动两个坐标时可重新求值仍未更新的另一个坐标，并持续重建依赖设置的界面。
- 现改为创建窗口时单次恢复坐标，移动期间只重启 350 ms 保存计时器，不写设置；拖动停稳后保存最终坐标，隐藏与退出时刷新尚未保存的位置。拖动区域使用 Qt DragHandler 的阈值和抓取规则启动系统移动，关闭与调整大小区域保持独立。
- 首页左上角加入全屏按钮，鼠标进入左上 76 × 44 区域或键盘聚焦时显示；F11 切换、Esc 退出。全屏前记录正常/最大化状态，退出时恢复；按钮纳入现有 QWindowKit 命中测试，不创建第二套窗口管理。
- 设置进入/返回采用 90 ms 淡出、190 ms 淡入及 230 ms 轻位移；分类内容采用 170 ms 淡入、210 ms 轻位移。只对场景图透明度和 Translate 动画，不逐帧重排控件；遵循现有动画开关，隐藏时终止分类动画。
- 设置主标题下内容缩进 16 dp，子标题下选项再缩进 14 dp；宽度同步扣除缩进，保留搜索定位与折叠行为。
- 高级选项入口改为“显示高级参数”，展开后仍显示“隐藏高级参数”。新增字符串提供中英文。
- 本轮按既有用户约定，仅执行 Windows 主程序构建与打包；未执行运行复现、自动测试或视觉审查。拖动问题依据源码修正，仍需在用户环境实际确认效果。
