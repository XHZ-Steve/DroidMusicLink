# 原文聚焦、设置缓存与运行记录（2026-11-13）

## 修改

- 歌词模式收起先执行 170 ms 原文聚焦：在共享歌词视图中以当前原文包围盒作为平滑遮罩窗口，隐藏其他行、译文与罗马音；随后进入原有 460 ms 布局时钟。
- 移动阶段只显示当前原文的词语，不再把整个滚动列表移动后淡出。记录真实 Glyph 几何，按前缀文本度量得到单行目标位置，逐词插值位置、缩放与字重；保留逐词时间戳与高亮进度，不增加每词离屏 Shader。
- 跨行词语沿额外的浅弧线归位，横向排布与字号共享缓动，避免合并时交叉、重影、空格挤压。原文位置受当前歌曲信息下沿约束，避免穿过标题、歌手或来源。
- 设置一级分类首次异步加载，此后保留实例；已折叠的歌词子分类首次展开才建立控件，之后也复用。搜索命中尚未创建的目标时，在分类加载后重新定位。保留设置值同步、分类导航和滚动记忆。
- 仅主页非当前行的 font.wordSpacing 设为字号的 -0.075；当前行保持 0，桌面歌词不变。实际渲染与 TextMetrics 使用相同参数。

## 实际运行验证

Windows Qt 6.11.1 / MinGW Release，系统 DPR 1.5。使用独立 --test-profile，不读取或修改真实配对数据。测试导入本地真实 The Scientist LRC、已保存媒体快照与封面样本，不冒充实时手机连接。

- 设置性能审计逐个等待六类首次加载，再按 70 ms 间隔调用真实 Qt 按钮 click，共 60 次。六类缓存全部 Ready，点击失败 0，缓存再次丢失 0。
- 修正折叠内容提前创建后，本次运行最大主线程计时间隔：首次访问 104 ms，复用后 29 ms；多轮复测热切换峰值为 13–31 ms，首次访问峰值在 15–128 ms 间变化。首次显示控件的初始化峰值未完全消除，不宣称所有切换均无掉帧。这里记录的是 10 ms 心跳的实际事件循环间隔，不是 GPU 帧耗时或 FPS，也不是 OS 冷启动保证。
- 可见主窗口执行三种布局循环并按帧截取实际渲染；分别覆盖短句、原文自动折为两行、640×760 窄窗口。检查先遮罩聚焦再合并、字号/字重变化、标题避让与最后单行落位。
- 运行读取当前行 QFont.wordSpacing 为 0；非当前行约 -2.094 / -1.719 逻辑像素，分别对应展开与紧凑字号。原有选中行间距保持不变。
- 使用 Windows Computer Use 对真实窗口打开玻璃下拉菜单并按 Esc 关闭，窗口仍可操作；未执行配对、安全或系统设置变更。
- 上述运行日志无 QML 报错或 Shader 错误。未连接手机，未把本轮测试当作 Android 通信、实时媒体控制或 SMTC 回归。
