# 主页对齐、滚动歌词与环境流动（1.1.0 preview4）

## 设置入口

设置 → 外观 → 主题与配色，分别展开「专辑聚焦布局位置」「展开封面布局位置」「展开歌词布局位置」。每种布局独立保存标题歌词左靠齐、居中、右靠齐，以及标题、歌词、封面的水平/垂直偏移。标题偏移作用于标题、歌手和来源组成的信息组；偏移范围为 ±180 Qt 逻辑像素，并根据实际画布空间约束。位置变化复用 320ms 布局过渡时钟；隐藏窗口不运行动画。

设置 → 歌词 → 主窗口歌词 → 排版 → 长句处理，可选择「滚动歌词」。桌面歌词也可独立选择同一策略。长句保持单行，在裁切容器内按歌词起止时间线性移动；暂停不自行跑马灯，拖动进度直接定位，不创建独立播放时钟。逐字高亮仍使用原时间轴。没有有效时间范围的文本不伪造滚动时间。移动方向的边缘有柔和渐隐，起点和终点保留完整首尾。

## 修复与实现

- 旧歌词在左侧额外预留了 4px 加至少 5px 的效果内边距，标题没有这层偏移；高亮缩放会放大偏差。主页现在对齐实际字形，不把描边/阴影留白作为对齐基准，译文、罗马音同步对齐。
- 居中/右对齐同时处理每一条自动换行，行尾空格不计入可见文字对齐边缘。使用 Qt 原生 Flow、TextMetrics 和缓存行边界，不逐帧解析歌词。
- 保留完整歌词/媒体时钟和现有原文格式补间。布局快照统一到主页歌词坐标；单行目标预先测量，但隐藏模板不运行逐字动画。滚动目标在交叉淡入时保持当前时间的位置。
- 加载使用标准 Qt Quick Controls BusyIndicator：140ms 延迟显示避免缓存闪烁，完成时立即淡出并让歌词淡入。切歌重置入场状态，窗口隐藏时停止加载旋转和淡入动画。
- 原背景最高流速仍约 57 秒完成一轮，中心位移仅 4.5%，所以几乎看不到。现在最高流速约 8.3 秒完成主运动周期，多个色域独立移动；默认速度仍较缓。沿用全分辨率解析 Shader 和固定空间抖动，不增加明显颗粒或模糊。谐波按共同周期无缝回绕，流速 0、关闭动态效果或隐藏窗口均停止移动。
- 搜索定位新增折叠参数时，等待分组展开完成后再次定位，避免滚动位置恢复把目标推回折叠区域之外。旧 `lyrics/alignment` 保留配置/预设导入兼容；主页显式布局预设优先，桌面歌词对齐不变。

未新增第三方依赖，继续使用已有 Qt 控件、场景图和 Shader；许可清单不变。Android 通信、配对、媒体控制、封面与歌词来源实现未改动。
