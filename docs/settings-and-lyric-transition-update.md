# 设置与歌词模式过渡更新

- 设置分类动画不再以透明度 0 和位移 10 为固定起点反复重启。快速切换时保留当前透明度和位移，仅第一次轻微淡入；同一事件循环中的选择通过 Qt.callLater 合并为最后一次请求，不添加等待 Android 或定时限流。
- 设置 ComboBox 使用统一 Popup.Item、透明选项列表、选中标记、圆角悬停状态及 GlassMaterial 背景，读取既有 popup 材质作用域；保留成熟控件的键盘、焦点、Esc 和点击外部关闭行为。标准材质仍使用降级表面。
- 从隐藏歌词进入歌词模式时，不再读取隐藏 Layout 的过期位置；起点在歌曲信息下方，并与封面下边缘下方的单行区域对齐。
- 主页的展开与单行歌词保持各自固定的文字布局，使用同一份解析结果和媒体时钟，通过共同的布局进度做缩放与字重交叉淡入淡出。避免每帧改变所有词的字号/字重导致文本重新塑形；完全不可见的视图不保留活动列表或歌词时钟订阅。
- 连续点击封面会从当前可见几何与样式进度继续；主页隐藏时不启动布局过渡。保留现有动画开关与窗口缩放取消旧插值的行为。
- 本轮仅编译 Windows 主程序、打包并提交源码；按用户既有约定未执行运行测试、性能测量或独立审查，不将编译通过视为视觉验收。
